# Squarekin

A self-contained illustrated QR studio.

Open `index.html` in a browser, or publish these files as a static website.
Upload the extracted files to the repository root, not this ZIP.
No installation, build step, API keys, or separate asset files are needed.
Music, illustrations, styles, scripts, and third-party notices are embedded in
`index.html`. `.nojekyll` is included for static publishing.
